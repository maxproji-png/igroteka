# Тапыши · ощущение тапа (3 варианта)

Макеты главного экрана-тапалки. В приложение tapyshi ничего не перенесено.
Открывать через HTTP (`python3 -m http.server` в этой папке) → `index.html`.

- `a/` — **Плавный досчёт**: крупный «+1» у пальца, мягкий блик, баланс досчитывается твином
  (текст ≤ 20 раз/с) с пульсом иконки; одна монета летит к балансу раз в 10 тапов, при посадке — блик по плашке.
- `b/` — **Canvas-частицы**: «+1», блик и 3–4 мини-монетки-искры рисуются на одном холсте (DPR ≤ 2),
  холст отдан в Web Worker (OffscreenCanvas; без него — тот же код в главном потоке). Баланс монет не
  принимает — быстро досчитывается и вспыхивает (opacity готового слоя), раз в 10 тапов ярче.
- `c/` — **Монетка-блик + барабан**: «+1» и монетка, которая выпрыгивает вбок, крутится и тает в блик;
  баланс — барабан цифр (translateY колонок) + блик по плашке; «coin burst» из 8 монет только на вехах комбо 25/50/75…
- `common/` — общие: та же 3D-модель Булочки (models/*.glb, без изменений), токены, спрайт монеты (рисуется один раз
  на canvas: ребро, обод, фаска, чекан-лапка, блик), ядро (комбо вариант A над головой, пружинка енота, энергия, хаптика).

Общие правила: всё, что двигается на тап, — только transform/opacity на заранее созданных пулах (WAAPI → композитор);
3D не перерисовывается на тап (радостная мордочка на время комбо запечена в 2D-снимок и включается opacity);
pointer events, `touch-action: manipulation`, без зума по двойному тапу и выделения; `prefers-reduced-motion`
(без движения, только мягкое появление/исчезание); хаптика `WebApp.HapticFeedback` (MAX) или `navigator.vibrate`, не чаще 1 раз / 70 мс.

## Мультитач (вариант A)
Зона тапа — вся игровая середина (`.tapzone`), а не только енот. Каждое новое касание из `touchstart.changedTouches`
считается отдельным тапом (несколько пальцев в одном кадре — несколько тапов), `preventDefault` (passive:false) гасит
скролл/зум/жесты; `pointerdown` используется только для мыши/пера, чтобы не было двойного счёта. Счёт без троттлинга;
склейка «+1» за 70 мс и редкие эффекты — только визуал. Тест: `tools/multitouch.js`, счётчик `window.__tapCount`.
