# Магазин · вкладка «Скины» (концепт Б «Список наборов»)

Вкладка встроена в `shop/index.html` рядом с «Бустами». По умолчанию открыты «Бусты»;
`?tab=skins` или `#skins` открывает «Скины», `#part-<id>` — окно части, `#set-<id>` — окно набора,
`?pet-<racoon|capybara|dragon|goose>` — выбранный питомец.

## Файлы
- `skins.css` — стили вкладки и окон (только токены палитры, Nunito).
- `skins.js` — данные, цены, окна части и набора, покупка через общий баланс `SHOP` из `../boosts.js`.
- `tab.js` — переключатель Бусты / Скины и список наборов.
- `manifest.js` — СГЕНЕРИРОВАН, руками не править.
- `assets/*.webp` — СГЕНЕРИРОВАНЫ из рендеров `/workspace/pet-skins`.

## Обновить рендеры (одна команда)
```
cd /workspace/tapyshi-redesign/final-concept && python3 tools/skins-assets.py /workspace/pet-skins
```
Скрипт пересобирает `assets/*.webp` (640 px) и `manifest.js` (тексты из skins.json, питомцы, части,
версия `v` = хеш skins.json + рендеров — кэш сбрасывается сам) и печатает, каким питомцам не хватает рендера.
После этого достаточно обновить страницу; `?v=` в index.html менять не нужно, если не менялись css/js.

## Цены — заглушки (плашка «цена-заглушка»)
Часть: обычный 1 500, эпический 4 000, легендарный 9 000. Весь набор = −15% от суммы частей
(5 100 / 13 600 / 30 600); докупка оставшихся частей — по тому же правилу.
Меняются в `skins.js` (объект `PART`).
