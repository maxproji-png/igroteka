# 99 ночей — прототип v0.8.2 (MVP: ночи 1–12, кооп за флагом)

3D-выживалка для мини-приложения «Тапыши» (MAX). Three.js r160 лежит локально (`vendor/`), без CDN.
Следует GDD v0.5 (`/workspace/99nights/gdd.md`):
- **Меню:** свой питомец (карточка), «Соло», «С другом» (лобби: код, 4 слота, чекбокс «Добрать случайных» — по умолчанию выкл.;
  «Начать» — только с флагом сервера, см. «Кооп»), «Поиск соперника» — «скоро» (без флага).
- **Карта этапов** по 6 ночей (16 этапов + финал 97–99): открыт / пройден / есть сохранение / закрыт / скоро. В MVP играбельны 1–6 и 7–12.
- **Соло** сохраняется каждое утро (localStorage `99n_v2_save`), «Продолжить», «Повторить ночь» после поражения;
  кооп по GDD — один этап за сессию. Аккаунт (`99n_acc`): открытые/пройденные этапы, монеты.
- **Наборы:** этап 1 — 8 веток / 4 камня / 3 ягоды / 1 лоскут на игрока, костёр 1 ур. (в самый первый раз — не горит, «Разжечь» → 50%);
  этап 2 с карты — костёр 3 ур., верстак 2 ур., 10/6/4/2.
- **Враги:** клубочки мглы (2 + доп. игроки, +1 в ночи 8–12), вороны с 1-й, Лунный Лось с 3-й (на этапе 2 держит один фонарик 0,8 с),
  мотыльки в 11–12 (3 / 4, в коопе с троих +1). Баланс §10 (гипотеза ГД, проверка — `qa/BALANCE_SIM.md`): ночи 1–3 — клубочек 1,5 ед/с и дует ≤ 8 с,
  ворон таскает только из сундука; ночи 4–9 — 2,5 ед/с до толчка, как v0.7.0; ночи 10–12 — клубочек 3,5 ед/с ≤ 20 с,
  мотылёк 1,0 ед/с до толчка; ночь 10 — горение ×1,15 (туман, §11.2). Ворон во всех ночах улетает только от толчка или через 15 с (§11.6).
- **Погода:** дождь в одну из ночей 7–9 (топливо ×1,3), ночь 10 «Ночь густого тумана» (две волны мглы: в соло 3 = 2 + 1, в коопе 4/5/6 = ceil(60%) + остаток; Лось у края света, +30 монет),
  11–12 — туман, ветер (×1,2) и мотыльки. Монеты: 15/25 за ночь, +100 за этап, +50 за первую игру дня.

## Запуск
Любой статический сервер (модули не работают с `file://`):
`python3 -m http.server 8099` → http://127.0.0.1:8099/

QA-флаги (только вместе с `?debug=1`): `night=N` — сразу соло в ночь N (1–12) нужного этапа со стартовым набором этого этапа, без сейва (ночь наступает через ~2 с); `unlock=1` — все этапы MVP открыты на карте (без записи в аккаунт). Пример: `?debug=1&night=10&fast=1`.

Флаги URL: `?fast=1` — весь мир ×6: часы, движение, враги (или `?fast=10`, до ×12; только для тестов, баланс — `test/balance-sim.mjs` при ×1), `?debug=1` — FPS/draw calls/треугольники (без флага оверлея нет), клавиша N — пропустить фазу (только с `?debug=1`, намеренно),
`?noadapt=1` — выключить авто-снижение разрешения, `?q=low|high` — качество эффектов (на тач-устройствах по умолчанию low), `?seed=N` — карта.

Управление: джойстик слева (плавающий), кнопка действия по контексту (собрать / рубить / в костёр / в сундук / толкнуть /
верстак), «Съесть», «Фонарик», «Крафт». Перетаскивание по экрану — доворот камеры. ПК: WASD, E/Пробел, Q, F, C, Esc.

## Архитектура (готовность к кооперативу на Colyseus)
- `js/sim.js` — вся логика. Без Three.js и DOM. Состояние — чистый JSON (`serialize/deserialize`), у всех сущностей
  есть `id`, генератор случайных чисел — в состоянии (`s.rng`), игроки лежат в `s.players[id]`.
- Ввод — только командами: `{t:'move',pid,x,z}`, `{t:'act',pid}`, `{t:'craft',pid,id}`, `{t:'eat',pid}`, `{t:'flash',pid}`.
  `step(state, dt, commands)` применяет их и двигает мир. Контекст кнопки (`context()`) и проверки дистанций считаются
  в симуляции — на сервере это будет античит из ТЗ.
- Симуляция выдаёт события `state.ev` (сбор, крафт, рассеивание, испуг, ночь/утро, победа/поражение);
  клиент их забирает и рисует эффекты/подсказки. Утро — точка автосейва и хук для начисления монет.
- `js/game.js` — клиент: рендер, HUD, джойстик/клавиатура → команды, камера, свет. Сам ничего не решает.
- Масштаб по числу игроков уже заложен (длина дня/ночи, расход топлива, число клубочков/воронов), подъём уставшего
  союзника — контекст `wake`.

План сети: Colyseus-комната держит `state` из `sim.js`, крутит `step()` на 20 Гц, принимает те же команды;
клиент отправляет `move` 10–15 Гц, рисует своего питомца с предсказанием, чужих и врагов — с интерполяцией 100–200 мс.
Сейв соло/«Игры с другом» переедет с localStorage на сервер.

## Модели
`js/assets.js` — карта ассетов (одна строка на модель; `url: null` или ошибка загрузки → процедурная заглушка).
Питомцы — GLB Тапышей. Мир — MVP-набор 3D-художника (`models/art/`, 26 GLB, ~490 КБ, без текстур):
- статика (деревья, пни, камни, ветки, куст + ягоды, костёр + насадки ур. 2/3, верстак, сундук, лежанка, фонарь, забор,
  ловушка, корзинка, брёвна-декор) запекается с цветами материалов в один меш → InstancedMesh, 1 draw call на тип;
  яркие emissive-части — отдельный меш без освещения; дальнее кольцо леса — LOD `pine_lod`/`oak_lod`;
- существа (мгла, ворон, Лунный Лось, мотылёк) — граф сцены + AnimationMixer (idle/walk/fly/peck); v0.8: все меши существа — один
  SkinnedMesh с жёсткой привязкой вершин к узлам, светящиеся части — атрибут `aGlow` → **1 draw call на врага** (было: Лось 11, ворон 6, мгла 3, мотылёк 4).
Пламя, свет, дым, дождь и туман — VFX, не меши.

## Камера и ночное освещение
- Окклюзия как в Roblox: отрезок камера→питомец проверяется против цилиндров деревьев/кустов/камней (раз в 0,1 с);
  заслонители рисуются полупрозрачными «призрачными» инстансами (+1 draw call на тип, только пока они есть),
  если камера упирается в крону/куст — плавно подъезжает ближе.
- Питомец ночью: френель-обводка (лунный rim), слабая лунная подсветка и тёплый свет костра по расстоянию (onBeforeCompile, 0 доп. draw calls).
- Над костром нет жёсткого столба: убран наш открытый цилиндр «дыма», остаются мягкие частицы пака.

## Производительность
Без теней (blob-тени — один InstancedMesh на всех), туман, pixel ratio ≤ 1.5 (на тач/low ≤ 1.35), адаптивно: вниз при FPS < 30 за 2 с, вверх при > 55 за 8 с, InstancedMesh для деревьев/травы/ресурсов.
v0.7: инстансы узлов упакованы (спрятанные не рисуются, пустые типы без draw call), питомец склеен в 3 меша (было 14–23).
С моделями художника: ~26–48 draw calls днём, 47–83 ночью (враги + погода), ~72–80k треугольников (v0.6: 41–62 / 61–98, 89–96k). Рендер на паузе, когда вкладка скрыта.
v0.8: враги — 1 draw call (SkinnedMesh), узлы мира отсекаются по пирамиде камеры и дальности тумана (пересборка раз в 0,2 с при движении камеры,
`?nocull=1` — выключить). Ночи 3 / 10 / 12, q=low, камера у костра: 70 / 79 / 90 → 50 / 52 / 58 draw calls (q=high 81 / 95 / 100 → 62 / 65 / 69), ~79–81k → 42–51k треугольников.
Долгий прогон `?fast=10` ночей 1–12 + три повтора этапа 7–12 (`node test/longrun.js`): 0 ошибок, рост памяти/геометрий/текстур/слушателей между повторами — 0.

## Кооп (шаг 1 NET_PLAN, только локально)
По умолчанию игра — только соло: сеть не грузится, «Поиск» и «Начать» в лобби — «скоро».
Флаг `?server=ws://127.0.0.1:2567` (разрешены только `127.0.0.1` / `localhost` / `[::1]`) подгружает `js/coop.js`
и `vendor/colyseus.js` (0.16.22) и включает: лобби «С другом» (код комнаты, вход по коду или `&room=КОД`, 4 слота,
«Добрать случайных», «Начать» у хоста), «Поиск» (случайная команда 2–4), один этап за заход, итог этапа.
Сервер авторитарный (тот же `sim.js`, 20 Гц): клиент шлёт команды, свой питомец — с предсказанием (`SIM.moveP`)
и мягкой коррекцией, чужие и враги — интерполяция на 120 мс. Таблички с именами, чат (8 шаблонов, текст до 80 знаков,
фильтр мата на сервере, заглушить/жалоба/выключить), пинги «Сюда!», переподключение после перезагрузки (токен в sessionStorage, 180 с).
Сервер: `cd server && npm i && npm run sync && node index.mjs` (слушает только 127.0.0.1:2567; `DEV=1` — тестовые хуки).
